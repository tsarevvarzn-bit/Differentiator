# Прочитаем красотульку из файла Tree3.txt
$${ { {\left(x\right)}^{\left(2\right)} }+{ \sin{\left(y\right)} } }-{\left(\cos{\left({ x }\cdot{ y }\right)}\right)}$$
# Упростим ее
$${ { {\left(x\right)}^{\left(2\right)} }+{ \sin{\left(y\right)} } }-{\left(\cos{\left({ x }\cdot{ y }\right)}\right)}$$
# Возьмем производную, это вам должны были объяснить в школе
$${ { { {\left(x\right)}^{\left(2\right)} }\cdot{\left({ {\left(\frac{ 2 }{ x }\right)}\cdot{ 1 } }+{ { \ln{\left(x\right)} }\cdot{ 0 } }\right)} }+{ { \cos{\left(y\right)} }\cdot{ 0 } } }-{\left({\left({ 0 }-{\left(\sin{\left({ x }\cdot{ y }\right)}\right)}\right)}\cdot{\left({ { x }\cdot{ 0 } }+{ { 1 }\cdot{ y } }\right)}\right)}$$
# Несколько простых преобразований, не буду утруждать себя объяснением
$${ { {\left(x\right)}^{\left(2\right)} }\cdot{\left(\frac{ 2 }{ x }\right)} }-{\left({\left({ 0 }-{\left(\sin{\left({ x }\cdot{ y }\right)}\right)}\right)}\cdot{ y }\right)}$$
# Подставляем числа обязательно, иначе на егэ снимут баллы
